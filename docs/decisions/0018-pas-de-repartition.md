# 0018 — Pas de répartition des tâches par personne

- **Date :** 2026-11-17
- **Statut :** Acceptée
- **Décideurs :** Romuald

## Contexte
Le plan v1 proposait une répartition (Romuald sur le produit, Olivier sur les données et le modèle, veille partagée). Romuald l'a refusée : il réalise l'essentiel, voire la totalité, du projet.

## Décision
- Aucune tâche n'est attribuée par personne dans `docs/plan.md`, `veille.md` ni le README.
- L'auteur de chaque question de veille est fixé au moment de la rédiger.

## Ce que le sujet impose malgré tout (rappel, pas une répartition)
- Veille : **chaque membre rédige et défend au moins 2 questions**.
- Soutenance : **chacun doit pouvoir expliquer n'importe quelle partie** ; le jury interroge chacun sur un module qu'il n'a pas écrit.
- Note collective **ajustée individuellement d'après l'historique Git** et les réponses.

## Conséquences
- Charge de travail concentrée sur une personne : le plan J1 → J15 reste le garde-fou (paliers dans l'ordre, extensions en dernier).
- La relecture des pull requests par l'autre membre reste prévue dans le workflow (fiche [0017](0017-workflow-git-et-github.md)).
